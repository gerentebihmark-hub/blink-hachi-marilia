# Segurança e Conformidade — Hachimitsu Marília

Este documento detalha as políticas de privacidade, segurança da informação e conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018) aplicadas à interface de multi-links (Blink) da **Hachimitsu** — unidade Marília, localizada na Av. Jesus Montolar, 1200 – Parque das Indústrias, Marília – SP, inscrita sob o CNPJ nº 20.989.222/0005-10.

## 1. Tratamento de Dados Pessoais (LGPD)

A Hachimitsu preza pela privacidade dos seus clientes. Nesta interface de redirecionamento, aplicam-se as seguintes regras de tratamento de dados:

* **Coleta Mínima:** Não coletamos dados pessoais diretamente através de formulários de cadastro nesta página de links. Os dados de contato e encomendas são inseridos exclusivamente pelo usuário ao iniciar a conversa no canal externo oficial (WhatsApp).
* **Finalidade:** O redirecionamento via WhatsApp tem como única finalidade a prestação do serviço de encomendas e atendimento ao cliente solicitado ativamente pelo usuário.
* **Consentimento:** Ao clicar nos botões de contato, o usuário ativamente manifesta seu consentimento para o redirecionamento.

## 2. Cookies e Rastreamento de Tráfego

Utilizamos tecnologias de rastreamento (como tags do Google Analytics e Pixel do Meta) exclusivamente para análise de performance de tráfego e melhoria da experiência de conversão:

* **Cookies Analíticos:** Utilizados para identificar a origem das visitas (ex: tráfego vindo do Instagram) e quais botões obtêm maior taxa de clique.
* **Anonimização:** Sempre que configurados, os dados de IP são anonimizados nos painéis de controle analíticos.
* **Revogação:** O usuário pode gerenciar o consentimento de cookies através do banner de privacidade presente no rodapé da página.

## 3. Segurança na Transferência de Dados

* **Criptografia em Trânsito:** Todo o tráfego de dados entre o navegador do usuário e nossos servidores é protegido utilizando o protocolo seguro **HTTPS (SSL/TLS)**. Isso impede a interceptação de cliques e desvios de navegação.
* **Integração de APIs de Terceiros:** A integração com o WhatsApp utiliza a API oficial de links diretos (`wa.me`), garantindo que nenhuma informação seja trafegada por intermediários não autorizados.

## 4. Direitos dos Titulares de Dados

Em conformidade com o Art. 18 da LGPD, os usuários têm o direito de obter, mediante requisição:
1. Confirmação da existência de tratamento de dados;
2. Acesso aos dados eventualmente mantidos;
3. Correção de dados incompletos ou desatualizados;
4. Eliminação de dados pessoais tratados com o consentimento do titular.
